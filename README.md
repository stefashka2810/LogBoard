# LogBoard

Frontend-приложение для работы с логами проектов. LogBoard даёт интерфейс для
авторизации, управления проектами и участниками, работы с API-ключами, поиска и
фильтрации логов, а также просмотра таймлайна и базовой аналитики.

## Стек

`Next.js 16`, `React 19`, `TypeScript`, `Redux Toolkit`, `RTK Query`,
`redux-persist`, `Tailwind CSS`, `Vitest`.

## Основные возможности

- публичный лендинг и FAQ;
- регистрация, вход и выход из системы;
- защищённый `dashboard` для просмотра логов;
- список проектов, выбор активного проекта и удаление проекта;
- управление участниками проекта и их ролями;
- создание и удаление API-ключей;
- поиск, фильтрация, сортировка и пагинация логов;
- таймлайн и агрегированная аналитика по выбранному периоду.

## Запуск

### Локально

```bash
npm install
npm run dev
```

Приложение будет доступно по адресу `http://localhost:3000`.

### Через Docker

```bash
docker compose up --build
```

После запуска приложение также будет доступно по адресу `http://localhost:3000`.
