# Технологии клиентской части LogBoard

| Технология | Причина выбора |
|---|---|
| `React` | Использован как основа клиентской части, поскольку позволяет строить интерфейс из переиспользуемых компонентов. |
| `Next.js` | Выбран для удобной маршрутизации, организации структуры приложения и разделения публичных и защищённых страниц. |
| `TypeScript` | Использован для строгой типизации данных и уменьшения количества ошибок при разработке. |
| `Redux Toolkit`, `RTK Query`, `redux-persist` | Использованы как единый стек для управления состоянием приложения, работы с API и сохранения части клиентских данных между перезагрузками страницы. |
| `Tailwind CSS v4` | Использован для быстрой разработки адаптивного и единообразного пользовательского интерфейса. |
| `Radix UI`, `lucide-react`, `motion` | Использованы для построения удобных интерфейсных компонентов, добавления иконок и реализации анимаций. |
| `Vitest` | Использован как основной инструмент для запуска тестов клиентской части. |
| `Testing Library` | Выбран для тестирования компонентов и пользовательских сценариев работы интерфейса. |
| `jsdom` | Использован для эмуляции браузерной среды при запуске frontend-тестов. |
